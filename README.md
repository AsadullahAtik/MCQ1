# Live MCQ: শিক্ষার্থীর মোবাইল অ্যাপ (Flutter)

**একটি অ্যাপ, তিন ভূমিকা:** লগইনের পর রোল দেখে নিজে নিজে সঠিক অংশ খোলে।
- **শিক্ষার্থী:** পরীক্ষার তালিকা, পরীক্ষা দেওয়া, ফলাফল, মেধাতালিকা, পাসওয়ার্ড বদল।
- **শিক্ষক:** পরীক্ষা বানানো (প্রশ্নসহ), চালু/বন্ধ, ফলাফল প্রকাশ, মেধাতালিকা, শ্রেণি/শাখা যোগ, শিক্ষার্থী যোগ ও পাসওয়ার্ড রিসেট।
- **অ্যাডমিন:** শিক্ষকের সব কাজ, সাথে শিক্ষক/অ্যাডমিন যোগ, ভূমিকা বদল, রিসেট, মোছা।
- প্ল্যাটফর্ম মালিক ও কিছু বিশেষ কাজ (প্রশ্ন সম্পাদনা, পরীক্ষার সময়সূচি, প্রশ্নভিত্তিক বিশ্লেষণ, শ্রেণি/শাখা নাম বদল ও মোছা) শুধু ওয়েবসাইটে।

সার্ভার আগের মতোই (একই REST API), অ্যাপ শুধু আরেকটি client।

**সার্ভার ঠিকানা অ্যাপের ভেতরেই বদলানো যায়:** লগইন পেজে "সার্ভার ঠিকানা" খুলে ঠিকানা লিখুন (যেমন `http://192.168.1.107:8080`), "সংযোগ পরীক্ষা করুন" চাপলে বলে দেয় সার্ভারে পৌঁছানো যাচ্ছে কিনা (না গেলে কারণসহ)। পিসির IP বদলালে নতুন APK বানাতে হয় না।

> **সৎ কথা:** এই sandbox-এ Flutter SDK নামানো যায় না, তাই এই কোড আমি **কম্পাইল বা চালিয়ে দেখিনি**। যত্ন করে লেখা ও API-র সাথে মিলিয়ে দেখা হয়েছে, কিন্তু আপনার পিসিতে প্রথমবার `flutter analyze` ও `flutter test` চালিয়ে যা আসবে আমাকে জানান, আমি ঠিক করে দেব (Java-র মতোই)।

## চালানোর ধাপ
```bash
# ১. Flutter SDK ইনস্টল থাকতে হবে (flutter doctor সবুজ)
cd livemcq_app
flutter create . --platforms=android,ios --org com.livemcq    # android/ ios/ ফোল্ডার তৈরি করে, lib/ ছোঁয় না
flutter pub get
flutter analyze
flutter test
# ২. সার্ভারের ঠিকানা দিয়ে চালান
flutter run --dart-define=API_URL=https://আপনার-ডোমেইন
#   লোকাল সার্ভার + Android emulator: ডিফল্ট http://10.0.2.2:8080 (এমুলেটর থেকে পিসির localhost)
#   আসল ফোন + লোকাল সার্ভার: --dart-define=API_URL=http://পিসির-LAN-IP:8080
```
- `http://` (HTTPS ছাড়া) ঠিকানায় Android ৯+ ডিফল্টে আটকে দেয়। শুধু ডেভেলপমেন্টে `android/app/src/main/AndroidManifest.xml`-এর `<application` ট্যাগে `android:usesCleartextTraffic="true"` যোগ করুন। প্রোডাকশনে HTTPS-ই ব্যবহার করবেন (deploy গাইড দেখুন)।
- APK বানাতে: `flutter build apk --release --dart-define=API_URL=https://আপনার-ডোমেইন`।

## কোড কোথায় কী
| ফাইল | কাজ |
|---|---|
| `lib/api.dart` | সার্ভারে সব কল, টোকেন ফোনে সংরক্ষণ, ৪০১ এ লগআউট |
| `lib/messages.dart` | সার্ভারের error code → বাংলা বার্তা (ওয়েবের মতো) |
| `lib/bn.dart` | বাংলা সংখ্যা, সময় `০২:০৫`, নম্বর |
| `lib/screens/login.dart` | লগইন (প্রতিষ্ঠান কোড মনে রাখে; শিক্ষক-অ্যাকাউন্ট ঢুকতে দেয় না) |
| `lib/screens/home.dart` | নিচের ৩ ট্যাব + পরীক্ষার তালিকা (এখন দিন / শীঘ্রই / অপেক্ষায় / ফলাফল / অংশ নেননি) |
| `lib/screens/exam.dart` | পরীক্ষা: সার্ভারের সময় থেকে কাউন্টডাউন, ১.৫ সেকেন্ড পর পর উত্তর ড্রাফট হিসেবে সার্ভারে, সময় শেষে নিজে জমা, বের হতে চাইলে সতর্কতা |
| `lib/screens/result.dart`, `board.dart` | ফলাফল + প্রতিটি প্রশ্নের সঠিক উত্তর; পরীক্ষাভিত্তিক ও সামগ্রিক মেধাতালিকা |
| `lib/screens/profile.dart` | নিজের তথ্য, পাসওয়ার্ড বদল, লগআউট (সব ভূমিকার জন্য) |
| `lib/screens/staff/*` | শিক্ষক/অ্যাডমিনের অংশ: পরীক্ষা (তালিকা, বিস্তারিত, তৈরি), শ্রেণি, শিক্ষার্থী, কর্মী |
| `test/api_test.dart` | `Api` ক্লাসের টেস্ট (নকল সার্ভার দিয়ে) |

## ওয়েবের থেকে যা আলাদা
- টাইমার ফোনের ঘড়ি নয়: সার্ভারের বলা "বাকি সেকেন্ড" থেকে `Stopwatch` দিয়ে গোনে (ফোনের ঘড়ি বদলালেও কিছু হয় না)।
- ব্যাক বোতাম চাপলে সরাসরি বের হয় না, আগে জিজ্ঞেস করে (পরীক্ষার মাঝখানে ভুলে বের হওয়া ঠেকাতে)।
- অ্যাপে ড্রাফট ইন্টারনেট না থাকলে প্রতি সেকেন্ডে আবার চেষ্টা করে; ফোন বন্ধ হয়ে গেলেও সার্ভার সময় শেষে সেভ করা উত্তর নিজেই জমা দেয়।
